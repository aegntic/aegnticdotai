TEMPORAL MEMORY ARCHITECTURE

It remembers.
Across sessions.
Across months.

Four distinct memory systems with a built-in forgetting curve. The agent no longer starts from zero every session.

Working Memory

Current session state, active files, in-flight operations. Cleared on session end.

Episodic Memory

What happened, when, and outcome. Stored persistently in gbrain PGLite. Queryable history.

Semantic Memory

What is known about architecture, conventions, dependencies. The agent's growing world model.

Procedural Memory

How things are done — build commands, test patterns, deployment procedures.
