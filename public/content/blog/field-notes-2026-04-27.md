> Retrospective field note for 2026-04-27, reconstructed on 16 November 2026. The archive date is not a claim of publication at the time.

“I've completed the draft.” Then there is no draft attached.

This is where agent workflows become exhausting. The summary sounds finished, but the person still has to ask for the output, find the link or assemble fragments scattered across messages.

Deliver the whole thing in the form needed next. Editable document if it needs editing. Project files if it needs running. Source links if someone needs to verify the research. Packaging is part of the job.

Checks should match the result. For a page, inspect the relevant screen sizes and interactions. For code, run the project's checks. For an external action, read the confirmation from the service. State what was actually verified rather than adding “everything works” to the end.

A stronger model should reduce this handoff friction. It does not need to narrate more activity or produce a more elaborate completion message. The response can be short when the result is there, opens correctly and includes the evidence needed to use it.
