# Audio Assets

This directory should contain the ambient audio file for the website:

- `ambient-cyberpunk.mp3` - Background ambient audio for the cyberpunk interface

For testing, you'll need to add a suitable ambient cyberpunk music track here. Due to copyright concerns, we don't include the audio file directly.

You can find royalty-free cyberpunk ambient music on sites like:
- Free Music Archive
- SoundCloud (with Creative Commons licenses)
- YouTube Audio Library
