Ten layers

Ten Layers
  1. Intake & Triage — T0–T4 complexity classifier routes every task
  2. Reasoning Mode Selection — System-1 / System-2 / Meta-cognition
  3. Context Budget Management — Danger zone detection, aggressive pruning
  4. Diff-Aware Context — Re-read before edit, chunked reads for large files
  5. Tool Result Blindness Prevention — Truncation awareness, suspicious result detection
  6. Semantic vs Syntactic Search — 8-point grep protocol for renames
  7. Generated File Awareness — Never edit generated code; find the source
  8. Phased Execution — Dead code removal → Implementation → Integration verification
  9. Rollback Planning — Starting commit hash, git worktree isolation
  10. Dependency Discipline — Lockfile detection, never mix package managers
