Five agents, one unfinished task

Parallel work needs ownership at the point where the pieces come together.

Field NotesRetrospective

Retrospective field note for 2026-02-09, reconstructed on 16 November 2026. The archive date is not a claim of publication at the time.

Five agents can produce five convincing summaries and still leave the job unfinished.

Someone has to assemble the result. The component needs to fit the page. The research needs to support the copy. The files need to be in the place the person can actually use them. Delegation does not make those responsibilities disappear.

Give each worker a bounded piece: the outcome, files it can change and the check that proves it is done. Two agents rewriting the same file are usually creating integration work for a third. Split along real boundaries instead of launching workers because the interface allows it.

A research handoff should contain the dated evidence. A writing handoff should contain the draft. A coding handoff should contain the change and test result. “I investigated” is not interchangeable with any of these.

Then check the assembled result. If the owner has to reconcile the assumptions, chase the missing artifact and rerun every check, the parallelism has mostly moved the work around.
