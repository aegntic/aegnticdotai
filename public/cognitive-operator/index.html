Cognitive Operator

Sovereign runtime thesis — an agent you own that compounds.

Four primitives
four primitives
Four Coordination Primitives
  1. Memory — Persistent, portable, private. What the agent knows across runs.
  2. Tools — Capabilities the agent can invoke. Sandboxed, auditable, composable.
  3. Policy — Rules the agent follows. Versioned, testable, overrideable.
  4. Loop — The coordination cycle. Plan → execute → verify → learn.
Principles
principles
Operating Principles
  • Local-first — Data stays on your machine. Cloud is optional sync, not primary storage.
  • Model-agnostic — Swap backends (local/cloud) without rewiring tools or memory.
  • No vendor lock-in — Plain JSON, SQLite, git. Export anytime.
  • Compounding — Every run improves the agent. Failed paths logged, successful patterns extracted.
