# Project: Aegntic Restoration

## Objective

Restore the Aegntic.ai website to its high-end, award-winning research foundation aesthetic, consolidating fragmented or missing components into a single, cohesive React/TypeScript application.

## Success Criteria

1. **Unified Navigation**: A single navbar that links to Home, About, Research (Blog), Projects, and Colabs.
2. **Design Consistency**: All pages must use the dark/neon cyan theme with metallic text, glow effects, and smooth animations.
3. **Restored Content**:
    - **Home**: Fully restored hero section with parallax and metallic effects.
    - **Research (Blog)**: Node-based grid listing and deep-dive article template.
    - **Projects**: Portfolio showcase grid.
    - **About**: Foundation mission page with tagline "zero knowledge, unlimited insight".
4. **Mobile Responsiveness**: Complete functional UI across all screen sizes.

## Constraints

- **Technology**: React 19, Vite, Tailwind CSS, Lucide React, Recharts (for viz).
- **Aesthetic**: Premium dark theme, neon cyan accents (#00f0ff), metallic typography.
- **Timeline**: Immediate restoration.

## Scope

### In Scope

- Porting existing content from HTML templates and fragmented React apps.
- Creating a unified routing system.
- Implementing the "Node Grid" for the research/blog index.
- Enhancing animations and visual effects site-wide.

### Out of Scope

- Changing the core brand identity.
- Database/Backend work (serving static/markdown content for now).
